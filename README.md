# מכונת דפי הנחיתה של dor digital

> **מדביקים קופי, מקבלים דף.** דף נחיתה בעברית ברמה של מעצבת, בלי מעצבת, בלי פיגמה ובלי לדעת קוד.

פלאגין ל-Claude Code. הקופי מגיע מוכן (מהשאלון והג'ם של דור, או משלך). הפלאגין מעצב אותו לדף HTML אחד, ממורכז, מותאם לעברית, עם תקנון, נגישות, באנר קוקיז, דף 404 ושער איכות. עיצוב טוב הוא לא כישרון, הוא נוסחה, והסקיל יודע אותה בעל פה.

## שתי הפקודות שצריך לזכור

### 1. `/lp-build`: מדביקים קופי, מקבלים דף

```
mkdir my-page && cd my-page
# שומרים את הקופי המוכן בקובץ copy.md בתיקייה הזאת
claude
/lp-build
```

מה קורה: הסקיל קורא את `copy.md`, מזהה בו את 13 המקטעים לפי הזרימה של הטקסט ולפי הערות העיצוב בסוגריים, בוחר לכל מקטע את הרכיב העיצובי שמתאים לו (מוקאפ צ'אט לכאב, לפטופ למוצר, כרטיס כהה למחיר), ובונה `index.html` עם `assets/`. הוא מציג את בחירת הצבעים בהודעה אחת וממשיך לבנות בלי לחכות. אין שאלות באמצע. מה שחסר מסומן `[למלא]` ונאסף לרשימה בסוף.

הקופי צריך להגיע כפרוזה, בלי כותרות סקשן, עם הערות עיצוב בסוגריים: `(תמונה של X)`, `(מוקאפ גדול)`, `(וידאו)`, `(כפתור: ...)`, `(טופס: ...)`, `עדויות -> *"..." - שם*`, `**שווי: X**`. זה בדיוק מה שהג'ם מוציא.

### 2. `/lp-redesign`: כתובת של דף קיים, מקבלים אותו מעוצב מחדש

```
/lp-redesign https://הכתובת-של-הדף
```

לדף שכבר באוויר ולא נראה טוב. הסקיל שומר על הקופי שכבר יש בדף, ומעצב אותו מחדש לפי אותה נוסחה. זה מה שנעשה בסוף המאסטרקלאס עם המתנדב.

## התקנה

בתוך Claude Code:

```
/plugin marketplace add dorkings/dor-digital-plugin
/plugin install landing-pages@dor-digital
```

דרישה אחת: Claude Code בטרמינל. כל השאר (Playwright לבדיקה, Vercel להעלאה) מותקן לבד כשצריך, ואם לא, הסקיל ממשיך בלעדיו ואומר מה דילג.

## הערכה המלאה: הפלאגין ועוד ארבעה כלים

הפלאגין הוא הליבה. לצידו יש ארבעה סקילים נוספים שדור משתמש בהם בכל דף. **הם משלימים את הפלאגין ולא מחליפים אותו:** הפלאגין בונה את הדף לפי הנוסחה, והארבעה הם העין החיצונית שבודקת אותו אחרי שהוא בנוי. הם לא נכתבו על ידי dor digital.

**סדר ההתקנה המומלץ.** קודם הפלאגין, כי הוא מה שבונה. אחר כך הארבעה, כי הם בודקים דף שכבר קיים.

```
/plugin marketplace add dorkings/dor-digital-plugin
/plugin install landing-pages@dor-digital
```

ואז, בטרמינל רגיל ולא בתוך קלוד קוד:

```bash
npx skills add https://github.com/Leonxlnx/taste-skill --skill "design-taste-frontend"
npx impeccable install
npx skills add emilkowalski/skills
claude mcp add playwright npx @playwright/mcp@latest
```

אחרי ההתקנה סוגרים את קלוד קוד ופותחים מחדש, אחרת הסקילים החדשים ושרת ה-MCP לא נטענים.

| הכלי | היוצר לפי הריפו | מה הוא נותן |
|---|---|---|
| `design-taste-frontend` | Leonxlnx | רשימת אנטי-פטרנים שמזהה מתי דף נראה כמו תבנית ולא כמו עיצוב |
| `impeccable` | pbakaus | מזהה אנטי-פטרנים ויזואליים שרץ על הדף החי ומחזיר רשימת ממצאים |
| `review-animations` ו-`emilkowal-animations` | emilkowalski | סטנדרט התנועה של אמיל קובלסקי: ease-out, מתחת ל-300 מילישניות, transform ו-opacity בלבד |
| Playwright MCP | חבילת `@playwright/mcp` | נותן לקלוד לפתוח את הדף בדפדפן אמיתי, לגלול, ללחוץ ולראות מה באמת קורה |

**איפה זה נכנס בצינור.** `/lp-qa` מריץ את ארבעתם בשלב "שער האיכות החיצוני". **אף אחד מהם אינו דרישת קדם:** כלי שלא מותקן נרשם "לא נבדק" והשער ממשיך בלעדיו.

**ובהתנגשות, הנוסחה של דור גוברת.** הכלים מעדיפים הירו לא ממורכז, סנס במקום סריף, ובלי כרטיסים. הנוסחה עושה את ההפך בכוונה, והיא זו שנמדדה על דפים שממירים. `/lp-qa` מפרט את נקודות ההתנגשות אחת אחת, כדי שקלוד לא "יתקן" דף תקין. החריג היחיד שאומץ מהכלים: אייקון ליד הכותרת במקום ריבוע אייקון מעליה.

`review-animations` מופעל **ידנית בלבד** (יש לו `disable-model-invocation`), כלומר קלוד לא יטען אותו מעצמו. מפעילים אותו בפקודה `/review-animations`.

## לפני הפלאגין: השאלון והג'ם

הפלאגין לא ממציא מילים. הוא מעצב מילים שכבר יש. למי שאין קופי, ארבעה צעדים:

1. **השאלון של דור.** עונים עליו פעם אחת, על כל השאלות, בכנות. משפט או שניים לכל שאלה מספיקים.
   https://docs.google.com/document/d/1IyPgM_JM8TEQGIGDpidzJuJ_PrmbfnI2NtX29gkHhXs/edit
2. **הג'ם של דור בג'מיני.** מדביקים את השאלון המלא (לא חלקי), והוא כותב את הקופי לפי 13 המקטעים. עובד מהטלפון, בלי להתקין כלום.
   https://gemini.google.com/gem/1w71qdVZK7D0xyR-OR3iaHRcUCkkk605h
3. **דוקס נקי.** מעתיקים את הפלט למסמך נקי ועוברים על העברית. הג'ם לפעמים מנסח כמו מתרגם.
4. **סימון מקומות לוויזואל.** בסוגריים: כאן תמונה, כאן מוקאפ, כאן עדויות. הסימונים הם הוראות למעצב, והמעצב הוא קלוד.

המסמך הנקי הוא ה-`copy.md` שמדביקים ל-`/lp-build`.

## 13 המקטעים

כל קופי טוב לדף נחיתה עובר את אותו מסע, בסדר הזה. לכל מקטע תפקיד פסיכולוגי אחד ורכיב עיצובי אחד שמתאים לו. הנוסחה המלאה, כולל הרכיב לכל מקטע, נמצאת ב-`plugins/landing-pages/skills/lp-build/references/13-sections.md`.

1. הירו: כאב, הבטחה, ושלושה "בלי"
2. חיבור עמוק לבעיה, בסצנות מהיום יום
3. הצגה עצמית: אנושיות, שליחות, ניסיון, וחזרה לקורא
4. סטוריטלינג שמנרמל את הבעיה
5. תקווה, מנגנון והוכחה ראשונה
6. הצגת המוצר. **כאן, ורק כאן, נחשף שם המוצר**
7. סילבוס חווייתי
8. בונוסים
9. תמחור: ערך, הקשר, למה נגיש, ורק אז המחיר
10. הנעה לפעולה רגועה
11. למי זה מתאים ולמי לא
12. הוכחות ושאלות ותשובות
13. מסר מלב אל לב

הכול עטוף באנגל מרכזי אחד. מקטע שאין לו חומר בקופי נמחק, לא מוצג ריק. הסקיל מדווח מה חסר ולמה זה מחליש את הדף.

## מה נוצר

```
my-page/
  copy.md       הקופי שהדבקת. מקור האמת לדף
  index.html    הדף עצמו. קובץ אחד, CSS כתוב ביד, אפס תלויות
  legal.html    תקנון, ביטולים, פרטיות, הצהרת נגישות
  404.html      דף שגיאה באותו עיצוב
  assets/       התמונות, הלוגו והנכסים של הדף
```

`index.html` עומד בזכות עצמו: אין בילד, אין npm install, אין פריימוורק. פותחים בדפדפן והוא עובד.

## שאר הפקודות

שמונה פקודות לשלבים בודדים, לחיבורים ולתיקונים. לא חייבים לזכור אותן.

| פקודה | מה היא עושה |
|---|---|
| `/lp` | **כל הצינור בפקודה אחת, מאותו קופי מוכן:** מעצבת, מוסיפה תקנון ו-404, ומריצה שער איכות. בערך רבע שעה. מי שאין לו קופי כותב לה "אין לי קופי", והיא מריצה במקום זה את הראיון של 15 השאלות בטרמינל |
| `/lp-brief` | קציר צבעים, לוגו ותמונות מאינסטגרם או מאתר, ואז הראיון. מפיקה `brief.md` |
| `/lp-copy` | כותבת קופי מתוך `brief.md`. מפיקה `copy.md` |
| `/lp-connect` | מחברת פיקסל מטא וטופס רב מסר, ומאמתת שהטופס באמת נשלח. כשהקונקטורים של מטא ושל רב מסר מחוברים היא שולפת את הפיקסל ואת הרשימה לבד, בונה דף תודה ומגדירה אירוע המרה |
| `/lp-campaign` | **הפקודה היחידה שנוגעת בכסף.** מרימה קמפיין מטא ראשון לדף שכבר באוויר, דרך הקונקטור של מטא. הקמפיין, הסט והמודעה נוצרים מושהים, מוצגת טבלת סקירה עם התקציב בשקלים, וההדלקה קורית רק אחרי אישור מפורש שני |
| `/lp-legal` | תקנון, ביטולים, פרטיות, הצהרת נגישות, דף 404, נוסח הודעת ההסכמה ופוטר |
| `/lp-qa` | שער איכות: 6 רוחבי מסך, ניגודיות, נגישות, אנטי פטרנים. מחזירה PASS או FAIL עם רשימת תיקונים |
| `/lp-ship` | מפרסמת לוורסל ומאמתת שהדף באמת עלה |

הסדר המומלץ אחרי `/lp-build`: `/lp-legal`, ואז `/lp-qa`, ואז `/lp-connect` כשיש פיקסל וטופס, ואז `/lp-ship`, ורק בסוף `/lp-campaign`.

### שני הקונקטורים, ואיפה מוסיפים אותם

`/lp-connect` ו-`/lp-campaign` עובדות גם בלי קונקטור, אבל הן חזקות הרבה יותר איתו. מוסיפים אותם **בקלוד שבדפדפן או באפליקציה**, לא בטרמינל: לוחצים על השם שלכם, `Settings`, ואז `Connectors` בסרגל הצד, ואז `+ Add` ו-`Add custom connector`. מדביקים את הכתובת ומאשרים פעם אחת.

| מערכת | הכתובת |
|---|---|
| מנהל המודעות של מטא | `https://mcp.facebook.com/ads` |
| מערכת הדיוור רב מסר | `https://ai.responder.live/mcp` |

**הקונקטור של מטא יושב על חשבון המודעות האמיתי שלכם, וזה כסף אמיתי.** קלוד מבקש אישור לפני כל פעולה שמשנה משהו בחשבון, אבל האישור הזה הוא אתם. קוראים לפני שמאשרים, ומתחילים בתקציב נמוך.

## מה הפלאגין לא עושה

- **לא כותב את הקופי בשבילך.** הקופי מגיע מהשאלון והג'ם, או ממך. `/lp-copy` קיימת למי שעברה את הראיון בטרמינל, אבל הדרך הראשית היא שאלון, ג'ם, דוקס נקי, `/lp-build`.
- **לא ממציא עובדות.** אין עדויות מומצאות, אין מספרים, אין שמות לקוחות ואין פרטי עסק. מה שחסר מסומן `[למלא]` ונאסף לרשימה אחת בסוף.
- **לא מוסיף מקטעים שהקופי לא ביקש.** אורך הדף שווה לאורך הקופי. מקטע בלי חומר נמחק.
- **לא משתמש בתמונות שאינן שלך.** אין לו מאגר תמונות. אין תמונה, יש הירו מוביל טיפוגרפיה.
- **לא מחליף ייעוץ משפטי.** התבניות המשפטיות נכתבות לפי מה שנמצא בפועל בקוד של הדף, ובעל העסק אחראי לאמת ולהתאים אותן לפני שהדף עולה לאוויר.
- **לא שואל שאלות באמצע.** זו לא מגבלה, זו ההבטחה. שאלה באמצע הריצה היא באג.

## קרדיט

נבנה על ידי **dor digital** עבור המאסטרקלאס בנקסט לבל.

ארבעת הסקילים הנוספים בסעיף "הערכה המלאה" אינם חלק מהפלאגין ולא נכתבו על ידי dor digital: `design-taste-frontend` של Leonxlnx, `impeccable` של pbakaus, `review-animations` ו-`emilkowal-animations` של emilkowalski, ו-Playwright MCP מחבילת `@playwright/mcp`.
